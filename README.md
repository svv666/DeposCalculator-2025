# DeposCalculator-2025
Deposit Calculator 2025 — Android-приложение на Kotlin для быстрого расчёта банковских депозитных вкладов.
Поддерживает сложный месячный процент, расчёт чистой прибыли после налога,выбор валюты (UAH/USD/EUR),
три языка интерфейса (EN/RU/UK), светлую и тёмную тему и сохранение настроек.

# DeposCalculator-2025
Deposit Calculator 2025 — a native Android app built with Kotlin for fast and accurate bank deposit calculations. It supports monthly compound interest,net profit after tax,currency selection (UAH/USD/EUR), three interface languages (EN/RU/UK),light and dark themes,and saved settings.
